# Auth0 Secure Agent Control Workflow

A self-contained example demonstrating secure AI agent tool access using
identity-based permissions, authorization checks, approval requirements,
and audit logging.

## Features

- User identity with roles and permissions
- Permission checks before tool execution
- Allowed and denied actions
- Approval requirement for sensitive actions
- Audit logs for authorization decisions
- Environment-based configuration
